ScheduledClicker v1.2.0 · Free and open source

Schedule a continuation prompt after access returns

Use a single prepared click or a bounded prompt loop. ScheduledClicker works with visible desktop targets and does not inspect your Codex account.

Simple mode: send an existing draft

  1. Keep the original chat open and prepare the next message without sending it.
  2. Read the reset time shown in your account and allow a buffer.
  3. Capture the Send button, choose the future time and confirm.
  4. Keep the desktop awake, unlocked and target unchanged.

Loop mode: repeat configured prompts

Choose a continuation prompt or sequence, capture input and Send in one window, set the first time and wait after each round, then set a maximum round count or deadline. Follow the complete loop setup guide.

The tool does not detect AI completion, inspect quotas, bypass limits or verify delivery. A five-hour interval does not guarantee that account access has reset. Use the time shown in your account and test a harmless target.

When a scheduled action can fail

  • The computer sleeps, locks or restarts.
  • The window moves, is covered, shows a dialog or changes its layout.
  • The selected chat changes while the same window remains open.
  • The service remains unavailable or rejects the message.

ScheduledClicker is an independent project, not affiliated with or endorsed by OpenAI. It does not call an OpenAI API or store credentials.
