프롬프트 반복 실행 설정

횟수 또는 종료 시각을 정해 같은 프롬프트나 순서별 내용을 반복합니다. Windows와 Mac의 위치 지정, 실제 시험 실행, 대기, 일시 정지 및 취소 방법을 설명합니다.

다운로드 및 설치
  1. 반복 모드에서 첫 실행 시각, 회차 후 대기 시간과 동작 간 지연을 설정합니다.
  2. 최대 횟수, 종료 시각 또는 둘 다 설정하세요. 첫 시험은 한 회차로 제한하고 버려도 되는 텍스트를 사용합니다.
  3. 매번 같은 프롬프트 또는 순서별 내용을 선택하고 마지막 내용 반복 여부를 정합니다. 기존 글 대체는 선택 사항이며 기본은 커서 위치에 삽입입니다.
  4. 각각 3초 카운트다운 후 입력란과 전송 버튼을 지정하세요. 같은 보이는 창 안의 두 지점이어야 하며 창 위치를 유지하세요.
  5. 한 회차 시험을 누르고 확인 내용을 읽으세요. 실제로 텍스트를 붙이고 전송을 클릭합니다. 결과를 확인한 뒤 예약을 시작하세요. 완료된 클릭 횟수는 메시지 전달 확인이 아닙니다.

편집한 프롬프트는 유지

아직 편집하지 않은 초기 프롬프트만 언어에 맞춰 바뀝니다: 繼續, Continue, 続けて, 계속, Weiter. 편집하거나 지운 뒤에는 사용자 내용을 유지합니다. 실행 중인 예약은 시작할 때 확정한 프롬프트를 사용합니다.

로컬 동작과 클립보드

앱에는 네트워크 접근, 계정, 광고, 원격 측정이 없습니다. 반복 모드는 클립보드를 덮어쓰며 이전 내용을 복원하지 않습니다. 텍스트가 클립보드 기록이나 대상 초안에 남을 수 있습니다. 간단 모드는 클립보드를 사용하지 않습니다. Mac의 진단 복사도 버튼을 누를 때 클립보드를 덮어씁니다. 예약과 위치는 재시작 후 보존되지 않습니다.

자주 묻는 질문

반복 간격은 언제부터 계산하나요?

각 회차의 동작이 끝난 뒤 대기를 시작합니다. 최대 횟수 또는 종료 시각을 적어도 하나 설정해야 하며 둘 다 설정하면 먼저 도달한 조건에서 멈춥니다. 클릭과 붙여넣기 사이의 지연은 회차 사이 대기와 별개입니다. AI 서비스의 사용량 주기와 자동 동기화되지 않습니다.

일시 정지, 취소와 긴급 중지는 어떻게 작동하나요?

회차 사이에 일시 정지하면 재개할 때 남은 대기 시간을 유지하지만 종료 시각은 계속 적용됩니다. 회차 실행 중 일시 정지하면 그 회차를 중단합니다. 취소, F8(일부 Mac 키보드는 Fn+F8) 또는 앱 종료는 이후 동작을 멈추지만 붙여넣은 글이나 완료한 클릭을 취소하지 못합니다. 다시 시작하기 전에 초안을 확인하세요.

AI 완료를 감지하거나 사용량 제한을 초기화하나요?

컴퓨터를 절전 또는 잠금 상태로 두지 말고 대상 창, 입력란과 대화를 그대로 유지하세요. 고정 좌표는 다른 대화나 이동한 입력란을 구별하지 못합니다. 전송 클릭은 전달 완료를 보장하지 않습니다. AI 답변 확인, 사용량 제한 우회, 초기화 시각 감지는 하지 않습니다.

실행이나 사용 중 문제가 있나요?

GitHub Issues로 신고하세요(게시하려면 GitHub 계정 필요). OS 및 앱 버전/빌드, 대상 앱, 재현 단계, 전체 오류를 포함하세요. Mac의 진단 복사는 빌드와 실행 단계 정보를 제공합니다. 공개 전에 확인하고 프롬프트, 개인 대화 또는 개인 파일 경로를 포함하지 마세요. 계정이 없어도 FAQ와 기존 Issues는 읽을 수 있습니다.
