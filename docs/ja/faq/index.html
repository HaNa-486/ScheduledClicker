ダウンロード・インストール

よくある質問

どのファイルをダウンロードすればよいですか？

Windows は ScheduledClicker.exe、Mac は ScheduledClicker-macOS-universal.zip です。Apple silicon と Intel は同じ ZIP を使います。.sha256 は検証用テキストで、アプリではありません。GitHub の Source code ZIP／TAR はソースコードで、そのまま使えるアプリではありません。正式版のダウンロードにログインは不要です。

システムの警告が出るのはなぜですか？

Windows EXE は未署名です。Mac は ad-hoc 署名で、Developer ID 署名・Apple 公証はありません。発行元不明の警告は、マルウェア、破損、組織ポリシーによるブロックとは異なります。下記の該当する手順に従い、保護機能を無効にしないでください。

2 つのモードでは何ができますか？

シンプルモードでは、未来のローカル日時または待機時間を指定して、シングル／ダブルクリックを 1 回実行します。ループモードでは同じプロンプトまたは順番に異なる内容を貼り付け、送信をクリックし、設定した制限内で繰り返します。時計、言語選択、外観ボタンは共通です。

どの言語に対応していますか？

起動時のシステム言語が中国語の場合は簡体字の設定も含め繁体字中国語、日本語・韓国語・ドイツ語の場合はそれぞれの言語、それ以外は英語で表示します。両モードで切り替え可能です。サイトも上部のリンクから同じ 5 言語を選べ、それぞれのページを個別に共有できます。

ライト／ダーク表示はどう切り替えますか？

アプリは起動時にシステムの外観を読み取ります。太陽／月ボタンは今回の起動中の両モードの外観を切り替えます。再起動するとシステム設定を読み直します。

言語を変えるとプロンプトも変わりますか？

言語に合わせて変わるのは未編集の初期プロンプトだけです：繼續、Continue、続けて、계속、Weiter。編集や削除をすると、その内容を保持します。実行中のスケジュールは開始時に確定したプロンプトを使います。

ループの間隔はいつから数えますか？

各回の操作が完了してから待機が始まります。最大回数または終了日時を少なくとも 1 つ指定し、両方あれば先に達した条件で停止します。クリック・貼り付け間の待機は、各回の間隔とは別です。AI サービスの利用枠とは同期しません。

一時停止、キャンセル、緊急停止はどう動作しますか？

各回の間で一時停止すると、再開時に残りの待機時間を引き継ぎます。終了日時は有効なままです。操作途中の一時停止はその回を停止します。キャンセル、F8（一部の Mac キーボードでは Fn+F8）、アプリを閉じる操作は後続処理を止めますが、貼り付け済みの文字やクリックは取り消せません。再実行前に下書きを確認してください。

クリップボードやデータはどう扱われますか？

アプリにネットワークアクセス、アカウント、広告、テレメトリはありません。ループはクリップボードを上書きし、以前の内容を復元しません。履歴や下書きに文字が残る場合があります。シンプルモードはクリップボードを使いません。Mac の診断コピーも押したときに上書きします。スケジュールと座標は再起動後に保存されません。

AI の完了や利用制限のリセットを検出しますか？

PC をスリープ・ロックさせず、対象ウィンドウ、入力欄、会話を変えないでください。固定座標では会話の切り替えや入力欄の移動を識別できません。送信クリックは配信完了を意味しません。AI の応答、利用制限の回避、リセット時刻の検出には対応しません。

どの範囲を検証しましたか？

所有者が Mac build12004 の機能と、Windows の初期プロンプトの言語切り替え、編集内容の保持、ループ試行を確認しました。両 OS の自動ビルド、スケジュール、翻訳、UI 検査は合格しています。ただし、すべての他社アプリ、画面構成、権限拒否、物理キーによる緊急停止を個別に検証したものではありません。

Mac でアクセシビリティ権限が必要なのはなぜですか？

別のアプリの操作にはアクセシビリティ権限が必要です。ループでは座標取得前、シンプルモードでは入力予約前に確認します。同じ通常のアクセシブルなアプリウィンドウ内で 2 点を取得してください。Safari 専用ではありません。時間、操作間隔、回数の数値欄は入力、マウスホイール、トラックパッドで調整できます。

起動や操作で困ったら

GitHub Issues から報告できます（投稿には GitHub アカウントが必要）。OS とアプリのバージョン／ビルド、対象アプリ、再現手順、エラー全文を記載してください。Mac の診断コピーでビルドや実行段階を確認できます。公開前に内容を確認し、プロンプト、私的な会話、個人のファイルパスを含めないでください。アカウントがない場合は FAQ や既存の Issues を参照できます。
