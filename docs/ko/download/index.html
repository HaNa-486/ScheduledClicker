Windows: 설치 없이 앱 열기

  1. Windows 버튼으로 ScheduledClicker.exe를 내려받아 실행할 로컬 폴더에 보관하세요. 설치 마법사는 없습니다.
  2. 아래 Windows 검증 안내로 파일을 확인한 후 EXE를 두 번 클릭하세요.
  3. 앱이 열리면 간단 모드로 무해한 클릭을 한 번 시험하세요. 실제 대화에서 사용하기 전에 버려도 되는 텍스트로 반복 동작을 시험하세요.

시스템에서 경고가 뜨는 이유는?

인식되지 않은 앱이라서 SmartScreen에 ‘Windows의 PC 보호’가 표시되면 공식 다운로드와 체크섬을 먼저 확인하세요. 계속 실행하기로 결정했고 Windows가 선택지를 제공한다면 ‘추가 정보’ → ‘실행’을 선택할 수 있습니다. 서명되지 않아 게시자를 알 수 없다고 표시될 수 있습니다. 악성 코드, 백신 탐지 또는 관리 기기 제한이면 중단하고 문제를 신고하거나 관리자에게 문의하세요. SmartScreen이나 백신을 끄지 마세요. 체크섬 일치만으로 안전을 보장하지는 않습니다.

운영체제 공식 안내

다운로드 파일 검증 방법 · 문제 신고

macOS: 설치 및 권한 설정

  1. Mac 버튼으로 ScheduledClicker-macOS-universal.zip을 받고 압축을 풀기 전에 ZIP을 검증하세요. Safari가 자동으로 풀었다면 ScheduledClicker.app이 이미 있을 수 있습니다. 체크섬을 확인하려면 원본 ZIP을 보관하거나 다시 받으세요.
  2. 필요하면 ZIP을 두 번 클릭해 압축을 풀고 Finder에서 ScheduledClicker.app을 ‘응용 프로그램’으로 드래그하세요. PKG 설치 파일이나 별도 Apple silicon 버전은 없습니다.
  3. ‘응용 프로그램’에서 앱을 여세요. 개발자나 공증을 확인할 수 없다는 경고가 뜨면 아래의 실행 안내를 참고하세요.
  4. ‘시스템 설정’ → ‘개인정보 보호 및 보안’ → ‘손쉬운 사용’에서 ScheduledClicker를 켜세요. 목록에 없다면 +로 응용 프로그램 폴더의 앱을 추가합니다. 요청 시 Mac 계정으로 인증하고 권한이 반영되지 않으면 앱을 종료한 후 다시 여세요.
  5. 간단 모드에서 무해한 클릭을 시험하세요. 반복 실행은 같은 보이는 대상 창에서 입력란과 전송 버튼을 지정한 후 버려도 되는 텍스트로 한 회차를 시험하세요. 이 권한은 다른 앱을 제어하도록 허용하므로 신뢰하는 앱에만 부여하세요.

시스템에서 경고가 뜨는 이유는?

확인되지 않은 개발자 또는 공증되지 않은 앱 경고라면 먼저 앱을 한 번 열어 보세요. 공식 다운로드를 신뢰하는 경우 ‘시스템 설정’ → ‘개인정보 보호 및 보안’의 ScheduledClicker 관련 메시지에서 ‘그래도 열기’를 선택하고, 제공되는 ‘열기’ 확인을 진행합니다. 악성 코드나 손상된 앱 경고에는 이 방법을 쓰지 말고 멈춘 뒤 정확한 메시지를 신고하세요. Gatekeeper를 끄거나 터미널 명령으로 격리 속성을 제거하지 마세요.

운영체제 공식 안내

이전 버전이나 미리 보기 버전을 교체할 때는 먼저 기존 앱을 종료하세요. 새 앱을 응용 프로그램에 넣고 손쉬운 사용 권한을 다시 확인합니다. 활성화된 항목이 이전 파일을 가리켜 권한이 계속 실패하면 이전 항목을 지우고 현재 앱을 다시 추가한 뒤 여세요. 위치도 다시 지정하세요. v1.2.0과 build12004는 릴리스 버전과 내부 빌드 번호이며 서로 다른 다운로드가 아닙니다.

다운로드 파일 검증 방법

체크섬은 파일이 게시된 내용과 일치하는지 확인하며 제작자의 신뢰성을 독립적으로 증명하지는 않습니다. 해당 .sha256을 텍스트로 열고 64자리 해시를 명령 결과와 비교하세요. 대소문자는 무시해도 됩니다. 다르면 실행하지 말고 공식 링크에서 다시 받으세요. 계속 다르면 신고하세요.

Windows · PowerShell

Windows: PowerShell을 열고 예시 경로를 실제 EXE 경로로 바꾸세요(파일 탐색기에서 우클릭 → 경로로 복사). 아래 명령의 Hash 항목과 ScheduledClicker-Windows.sha256을 비교합니다. 전체 경로를 쓰므로 PowerShell의 현재 폴더는 상관없습니다.

아래는 예시입니다. 다운로드한 파일의 실제 경로로 바꾸세요.

Get-FileHash -LiteralPath "C:\Users\YOUR_NAME\Downloads\ScheduledClicker.exe" -Algorithm SHA256

SHA-256 체크섬 (텍스트 파일)

macOS · Terminal

Mac: 터미널에 shasum -a 256과 공백 하나를 입력한 후 Finder의 원본 ZIP을 터미널로 드래그해 전체 경로를 넣고 Return을 누르세요. 결과의 처음 64자리를 ScheduledClicker-macOS-universal.sha256과 비교합니다. 경로를 직접 입력하면 공백이 있는 경로는 따옴표로 감싸세요.

아래는 예시입니다. 다운로드한 파일의 실제 경로로 바꾸세요.

shasum -a 256 "/Users/YOUR_NAME/Downloads/ScheduledClicker-macOS-universal.zip"

SHA-256 체크섬 (텍스트 파일)

이전 버전에서 업데이트

기존 앱을 종료하고 공식 v1.2.0 파일로 교체하세요. Actions 파일이나 GitHub 로그인은 필요 없습니다. 예약과 위치는 보존되지 않으므로 다시 설정하세요. 되돌릴 필요가 있을 때만 기존 파일을 별도로 보관하세요. 과거 버전에는 현재 반복 기능 일부가 없습니다.

릴리스 안내 및 모든 파일

자주 묻는 질문

어떤 파일을 다운로드해야 하나요?

Windows는 ScheduledClicker.exe, Mac은 ScheduledClicker-macOS-universal.zip을 선택하세요. Apple silicon과 Intel은 같은 ZIP을 사용합니다. .sha256은 검증용 텍스트이지 앱이 아닙니다. GitHub의 Source code ZIP/TAR는 소스 코드이며 바로 실행할 앱이 아닙니다. 공식 릴리스 다운로드에는 로그인이 필요 없습니다.

시스템에서 경고가 뜨는 이유는 무엇인가요?

Windows EXE는 서명되지 않았습니다. Mac 앱은 ad-hoc 서명이며 Developer ID 서명이나 Apple 공증은 없습니다. 알 수 없는 게시자 경고는 악성 코드, 파일 손상, 조직 정책 차단과 다릅니다. 해당 상황의 안내를 따르며 앱을 실행하려고 시스템 보호를 끄지 마세요.

실행이나 사용 중 문제가 있나요?

GitHub Issues로 신고하세요(게시하려면 GitHub 계정 필요). OS 및 앱 버전/빌드, 대상 앱, 재현 단계, 전체 오류를 포함하세요. Mac의 진단 복사는 빌드와 실행 단계 정보를 제공합니다. 공개 전에 확인하고 프롬프트, 개인 대화 또는 개인 파일 경로를 포함하지 마세요. 계정이 없어도 FAQ와 기존 Issues는 읽을 수 있습니다.
