Windows: open the portable app

  1. Download ScheduledClicker.exe using the Windows button. Keep it in a local folder where you want to run it; there is no installation wizard.
  2. Verify the downloaded file using the Windows instructions below, then double-click the EXE.
  3. If the app opens, choose Simple mode and test one harmless click first. Test a loop on disposable text before using a real conversation.

Why does the system show a warning?

If SmartScreen says Windows protected your PC because the app is unrecognized, confirm the official download and checksum first. If you choose to proceed and Windows offers it, select More info → Run anyway. This unsigned build may display Unknown publisher. If the message reports malware, an antivirus detection or a managed-device restriction, stop and use the report link or contact your administrator. Do not turn off SmartScreen or antivirus; a matching checksum alone does not prove safety.

macOS: install and grant permission

  1. Download ScheduledClicker-macOS-universal.zip using the Mac button and verify the ZIP before extracting it. If Safari already extracted the download, you may already have ScheduledClicker.app; keep or download the original ZIP if you want to verify its checksum.
  2. Double-click the ZIP to extract it if needed. In Finder, drag ScheduledClicker.app into Applications. There is no PKG installer and no separate Apple silicon download.
  3. Open the app from Applications. If macOS cannot verify the developer or notarization, review the specific opening instructions below.
  4. Open System Settings → Privacy & Security → Accessibility. Enable ScheduledClicker; if it is missing, use + and select the app in Applications. Approve with your Mac credentials if requested, then quit and reopen ScheduledClicker if the permission is not recognized.
  5. Choose Simple mode for a harmless click test. For a loop, capture the input and Send positions in the same visible target window and try one round with disposable text. Permission allows control of other apps; grant it only if you trust this app.

Why does the system show a warning?

For an unidentified-developer or unnotarized-app warning, first try opening the app once. If you trust this official download, go to System Settings → Privacy & Security, find the message about ScheduledClicker and choose Open Anyway, then confirm Open if offered. Do not use this as a remedy for a malware or damaged-app warning; stop and report the exact message instead. Do not disable Gatekeeper or remove quarantine with a terminal command.

Official platform guidance

Replacing a preview or older copy? Quit the old app before moving the new copy into Applications. Check Accessibility again: if the enabled entry points to the old copy and permission still fails, remove that entry and add the current app from Applications, then reopen it. Capture positions again. v1.2.0 uses Mac build12004; these are the release version and internal build number, not two different downloads.

How to verify your download

A checksum checks that your bytes match the published file; it does not independently establish trusted authorship. Download the matching .sha256 file and open it as text. Compare its 64-character hash with your command result; uppercase/lowercase does not matter. If they differ, do not open the app: download again from the official link and report a repeated mismatch.

Windows · PowerShell

Windows: open PowerShell. Replace the example path with the EXE's actual location (File Explorer → right-click the file → Copy as path). Run the command below and compare the Hash field with ScheduledClicker-Windows.sha256. Use the full path so your current PowerShell folder does not matter.

Example only — replace the path with your downloaded file:

Get-FileHash -LiteralPath "C:\Users\YOUR_NAME\Downloads\ScheduledClicker.exe" -Algorithm SHA256

SHA-256 checksum (text file)

macOS · Terminal

Mac: open Terminal. Type shasum -a 256 followed by a space, drag the original ZIP from Finder into Terminal to insert its full path, then press Return. Compare the first 64 characters with ScheduledClicker-macOS-universal.sha256. If you type a path yourself, put quotes around paths containing spaces.

Example only — replace the path with your downloaded file:

shasum -a 256 "/Users/YOUR_NAME/Downloads/ScheduledClicker-macOS-universal.zip"

Upgrading from an older version

Quit the old app and replace it with the official v1.2.0 file. You do not need Actions artifacts or a GitHub account to download. Schedules and captured positions do not persist; set them again. Keep the old file separately only if you need a rollback. Historical versions do not include all current loop features.

Common questions

Which file should I download?

Choose ScheduledClicker.exe for Windows or ScheduledClicker-macOS-universal.zip for Mac. Apple silicon and Intel use the same ZIP. The .sha256 files are text checksums, not apps. GitHub's Source code ZIP/TAR files contain source, not the ready-to-run app. Official release downloads do not require sign-in.

Why does my system show a warning?

The Windows EXE is unsigned. The Mac app is ad-hoc signed, not Developer ID signed or Apple-notarized. An unfamiliar-publisher warning is different from a malware, damaged-file or organization-policy block. Follow the matching instructions below; do not disable system protection to run the app.

Need help opening or using the app?

Report a problem on GitHub Issues (a GitHub account is required to post). Include Windows/macOS version, app version/build, target app, reproduction steps and the full error. On Mac, Copy diagnostics can supply build and execution-stage details; inspect it before posting. Do not include prompts, private conversations or personal file paths in public reports. If you have no account, check the FAQ and existing issues first.
