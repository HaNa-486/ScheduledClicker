무료 오픈 소스 · Windows 및 macOS

클릭 예약과 프롬프트 반복 입력.

ScheduledClicker v1.2.0은 Windows 11과 macOS 13 이상에서 작동하는 무료 로컬 도구입니다. 클릭을 예약하거나 프롬프트 입력과 전송 클릭을 반복할 수 있으며 5개 언어와 라이트/다크 모드를 지원합니다.

한 창에서 두 가지 모드

간단 모드는 미래의 로컬 시각이나 대기 시간을 정해 한 번의 단일 또는 더블 클릭을 실행합니다. 반복 모드는 같은 프롬프트나 순서별 내용을 붙여넣고 전송을 클릭하며 설정한 제한 안에서 반복합니다. 두 모드는 실시간 시계, 언어 선택과 테마 버튼을 공유합니다.

5개 언어와 수동 전환

앱 시작 시 중국어 시스템은 간체 설정을 포함해 번체 중국어로, 일본어·한국어·독일어 시스템은 해당 언어로, 나머지는 영어로 표시됩니다. 두 모드에서 언어를 바꿀 수 있습니다. 웹사이트도 위쪽 링크로 같은 5개 언어를 선택하며 언어별 페이지를 따로 공유할 수 있습니다.

라이트 및 다크 모드

앱은 시작할 때 시스템 화면 모드를 확인합니다. 해/달 버튼은 현재 실행 중인 두 모드의 화면을 바꿉니다. 앱을 다시 시작하면 시스템 설정을 다시 읽습니다.

로컬 동작과 클립보드

앱에는 네트워크 접근, 계정, 광고, 원격 측정이 없습니다. 반복 모드는 클립보드를 덮어쓰며 이전 내용을 복원하지 않습니다. 텍스트가 클립보드 기록이나 대상 초안에 남을 수 있습니다. 간단 모드는 클립보드를 사용하지 않습니다. Mac의 진단 복사도 버튼을 누를 때 클립보드를 덮어씁니다. 예약과 위치는 재시작 후 보존되지 않습니다.

자주 묻는 질문

어떤 파일을 다운로드해야 하나요?

Windows는 ScheduledClicker.exe, Mac은 ScheduledClicker-macOS-universal.zip을 선택하세요. Apple silicon과 Intel은 같은 ZIP을 사용합니다. .sha256은 검증용 텍스트이지 앱이 아닙니다. GitHub의 Source code ZIP/TAR는 소스 코드이며 바로 실행할 앱이 아닙니다. 공식 릴리스 다운로드에는 로그인이 필요 없습니다.

두 모드에서는 무엇을 할 수 있나요?

간단 모드는 미래의 로컬 시각이나 대기 시간을 정해 한 번의 단일 또는 더블 클릭을 실행합니다. 반복 모드는 같은 프롬프트나 순서별 내용을 붙여넣고 전송을 클릭하며 설정한 제한 안에서 반복합니다. 두 모드는 실시간 시계, 언어 선택과 테마 버튼을 공유합니다.

AI 완료를 감지하거나 사용량 제한을 초기화하나요?

컴퓨터를 절전 또는 잠금 상태로 두지 말고 대상 창, 입력란과 대화를 그대로 유지하세요. 고정 좌표는 다른 대화나 이동한 입력란을 구별하지 못합니다. 전송 클릭은 전달 완료를 보장하지 않습니다. AI 답변 확인, 사용량 제한 우회, 초기화 시각 감지는 하지 않습니다.

실행이나 사용 중 문제가 있나요?

GitHub Issues로 신고하세요(게시하려면 GitHub 계정 필요). OS 및 앱 버전/빌드, 대상 앱, 재현 단계, 전체 오류를 포함하세요. Mac의 진단 복사는 빌드와 실행 단계 정보를 제공합니다. 공개 전에 확인하고 프롬프트, 개인 대화 또는 개인 파일 경로를 포함하지 마세요. 계정이 없어도 FAQ와 기존 Issues는 읽을 수 있습니다.
