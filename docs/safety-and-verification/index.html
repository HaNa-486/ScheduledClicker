What ScheduledClicker does, what it cannot do, and how releases are checked

The project publishes source, build scripts, test evidence, checksums, and residual risks so users can make an informed decision.

Local-only privacy design

The Windows and macOS applications have no network client, analytics, telemetry, account, sign-in, cloud storage, clipboard access, startup entry, or persistent schedule database. Coordinates and schedules stay in process memory and disappear when the app closes.

What the `.sha256` file is for

A SHA-256 checksum is a deterministic fingerprint of a file. The macOS checksum download is a 103-byte text file containing the expected fingerprint of the ZIP. It is not an installer and should not be opened as an application.

Verify on macOS

In Terminal, run:

shasum -a 256 ScheduledClicker-macOS-universal.zip

Compare the result character-for-character with `ScheduledClicker-macOS-universal.sha256` or the value published in the verification report.

Verify on Windows

In PowerShell, run:

Get-FileHash .\ScheduledClicker.exe -Algorithm SHA256

Automated evidence

  • 10 Windows scheduler tests.
  • 21 macOS scheduler and failure-path tests.
  • Windows launch smoke test and Microsoft Defender scan.
  • macOS non-clicking event-construction self-test.
  • Aqua and Dark Aqua UI readability and visibility checks.
  • Universal `x86_64 arm64` architecture inspection.
  • Property-list validation, ad-hoc signature verification, archive inspection, and downloaded-asset re-hashing.

Limits that checksums and tests do not remove

  • Windows downloads are unsigned and may trigger SmartScreen.
  • The macOS app is ad-hoc signed, not Developer ID signed or notarized.
  • A correct fixed coordinate can become unsafe when visible content moves.
  • Sleeping, locking, signing out, changing displays, or moving the target window can prevent or invalidate a click.
  • No automated test can guarantee that every third-party application accepts simulated input.

Practical rule: test a harmless target first and do not automate payments, deletion, publication, permission grants, or irreversible actions.
