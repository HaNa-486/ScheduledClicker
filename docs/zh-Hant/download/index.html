Windows：開啟免安裝程式

  1. 使用 Windows 按鈕下載 ScheduledClicker.exe，放在你要執行的本機資料夾，不會有安裝精靈。
  2. 依下方 Windows 校驗說明確認檔案後，雙擊 EXE。
  3. 程式開啟後，先用簡單模式測試一次無害點擊。循環模式先用可丟棄的文字試跑，再操作真正的對話。

為什麼系統會跳出警告？

若 SmartScreen 因不認識此程式而顯示「Windows 已保護您的電腦」，請先確認官方來源與校驗碼。若你決定繼續，且 Windows 有提供選項，可點「其他資訊」→「仍要執行」；未簽章版本可能顯示「未知的發行者」。若訊息明確指出惡意程式、防毒偵測或受管理裝置限制，請停止，使用回報連結或聯絡管理員。不要關閉 SmartScreen 或防毒；校驗碼一致也不等於安全保證。

macOS：安裝與授權

  1. 使用 Mac 按鈕下載 ScheduledClicker-macOS-universal.zip，先校驗 ZIP 再解壓縮。Safari 若已自動解壓縮，你可能已取得 ScheduledClicker.app；要校驗 ZIP 時，請保留或重新下載原始 ZIP。
  2. 必要時雙擊 ZIP 解壓縮，在 Finder 將 ScheduledClicker.app 拖到「應用程式」。沒有 PKG 安裝程式，也不需要另外找 Apple silicon 版本。
  3. 從「應用程式」開啟 App。若 macOS 無法驗證開發者或公證，請參照下方首次開啟說明。
  4. 開啟「系統設定」→「隱私權與安全性」→「輔助使用」，啟用 ScheduledClicker；若清單沒有，按 + 選取「應用程式」內的 App。系統要求時以 Mac 帳號驗證；若權限仍未生效，結束並重新開啟 ScheduledClicker。
  5. 先用簡單模式測試無害點擊。要測循環時，在同一個可見的目標視窗擷取輸入框與送出按鈕，以可丟棄文字試跑一輪。此權限允許控制其他程式，請只授予你信任的 App。

為什麼系統會跳出警告？

遇到無法辨識開發者或未公證提醒時，先嘗試開啟 App 一次。若你信任這份官方下載，前往「系統設定」→「隱私權與安全性」，找到 ScheduledClicker 的提醒並選「強制打開」，接著依畫面確認「打開」。若是惡意程式或 App 損毀警告，請停止並回報完整訊息，不要套用此方法。不要停用 Gatekeeper，也不要用終端機指令移除隔離標記。

作業系統官方說明

替換預覽版或舊版本時，請先結束舊 App，再將新檔案移入「應用程式」。重新檢查「輔助使用」：若啟用項目指向舊檔且權限持續失效，可移除該舊項目，重新加入「應用程式」內的現有 App，再開啟程式。請重新擷取位置。v1.2.0 與 build12004 分別是正式版本與內部建置編號，不是兩個不同下載。

如何校驗下載檔案

校驗碼用來確認檔案內容與公布的版本一致，不能獨立證明作者可信。下載對應的 .sha256，以文字方式開啟，將其中 64 字元雜湊與指令結果比較，大小寫可忽略。不一致時不要開啟程式，請從官方連結重下載；若仍不一致，請回報。

Windows · PowerShell

Windows：開啟 PowerShell，將範例路徑替換成 EXE 的實際位置（檔案總管右鍵點選檔案→複製路徑）。執行下方指令，將 Hash 欄位與 ScheduledClicker-Windows.sha256 比對。使用完整路徑，不必先切換 PowerShell 的目前資料夾。

以下僅為範例，請替換成下載檔案的實際路徑：

Get-FileHash -LiteralPath "C:\Users\YOUR_NAME\Downloads\ScheduledClicker.exe" -Algorithm SHA256

SHA-256 校驗碼（文字檔）

macOS · Terminal

Mac：開啟「終端機」，輸入 shasum -a 256 再加一個空白，將原始 ZIP 從 Finder 拖進終端機以填入完整路徑，再按 Return。將結果前 64 個字元與 ScheduledClicker-macOS-universal.sha256 比較。自行輸入路徑時，含空白的路徑要加引號。

以下僅為範例，請替換成下載檔案的實際路徑：

shasum -a 256 "/Users/YOUR_NAME/Downloads/ScheduledClicker-macOS-universal.zip"

從舊版升級

結束舊程式，以官方 v1.2.0 檔案取代，不必找 Actions 產物，也不必登入 GitHub。排程與位置不會保留，請重新設定；若需要退回舊版，可另外保存舊檔。歷史版本不含所有現有循環功能。

常見問題

應該下載哪個檔案？

Windows 請選 ScheduledClicker.exe；Mac 請選 ScheduledClicker-macOS-universal.zip，Apple silicon 與 Intel 共用同一檔案。.sha256 是校驗文字檔，不是程式。GitHub 的 Source code ZIP／TAR 是原始碼，不是可直接執行的 App。正式版下載不需要登入。

為什麼系統會跳出警告？

Windows EXE 尚未簽章。Mac App 使用 ad-hoc 簽章，沒有 Developer ID 簽章或 Apple 公證。未知發行者提醒，與惡意程式、檔案損毀或組織政策阻擋不同。請依下方對應情境處理，不要為了執行程式而關閉系統防護。

開啟或使用時遇到問題？

請到 GitHub Issues 回報（發文需要 GitHub 帳號）。提供 Windows／macOS 版本、程式版本／build、目標 App、重現步驟與完整錯誤。Mac 可用「複製診斷」取得建置及執行階段資訊，貼出前請先檢查。公開回報不要包含提示詞、私人對話或個人檔案路徑。沒有帳號時，可先查閱常見問題及既有 Issues。
