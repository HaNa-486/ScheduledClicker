Before running

Read the safety and verification guide. Windows may show SmartScreen because the EXE is unsigned. macOS may require Control-click → Open and explicit Accessibility permission because the app is not notarized.

Preview 1.2.0-preview.2: loop mode, languages and appearance

This is a test candidate, separate from the stable v1.1.2 buttons above. Windows redesign owner testing passed; preview-2 fixes pass regression checks. Mac build 12002 failed native Safari and Word tests. The current Mac build 12003 changes foreground verification and activation; native owner acceptance is still pending.

  1. Open the verified preview build (source commit 05861ea). Both platform jobs passed.
  2. For macOS, download the exact build 12003 artifact named ScheduledClicker-macOS-universal. Confirm build 12003 in the app title; capture labels should name your target app. If a trial fails, use Copy diagnostics. GitHub sign-in is required; artifacts expire.
  3. Extract the outer artifact ZIP, then extract ScheduledClicker-macOS-universal.zip inside it. The app supports macOS 13+ on Apple silicon and Intel.
  4. Compare shasum -a 256 ScheduledClicker-macOS-universal.zip with its adjacent .sha256 file. Move the extracted app to Applications before granting Accessibility permission.

The app is ad-hoc signed, not Apple-notarized. If macOS blocks opening, use its Privacy & Security approval controls; do not disable Gatekeeper globally. After replacing an older build, macOS may require renewed Accessibility approval. Begin with a disposable text target and one trial round.

For Windows preview source/build instructions and current candidate evidence, see the feature branch. Read the feature and behavior guide.
