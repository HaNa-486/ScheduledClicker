# Mac acceptance repair contract

- User authorizes preview repairs, not stable release. Target reported: Safari on MacBook Air, lid closed, one external display; latest private environment details are in the owner report.
- Focus: Capture with system-wide AX hit-test, normalize owning AXWindow/PID and retain window plus topLevel identities and AX geometry. Every stage must compare current hit with the original captured identity. Focused/keyboard windows and topLevels must also match the original. Never use CG rectangle ownership, PID-only inference, geometry proximity or browser whitelist. Clipboard writes follow validation.
- Rationale: [Apple hit-test API](https://developer.apple.com/documentation/applicationservices/1462077-axuielementcopyelementatposition), [window attribute](https://developer.apple.com/documentation/applicationservices/kaxwindowattribute) and [top-level attribute](https://developer.apple.com/documentation/applicationservices/kaxtopleveluielementattribute). [WebKit remote accessibility IDs](https://bugs.webkit.org/show_bug.cgi?id=297546) explain why leaf PID cannot be assumed equal to owning-window PID. Build12003 diagnostics now confirm the wrong CG owner was Dock.
- Diagnostic errors contain API stage/result or identity mismatch code, never prompt text, window title or clipboard contents. Unknown identity fails closed.
- Starter: current locale at construction and idle manual switches; only untouched initial prompt is UI-owned. Editing or deleting it permanently ends auto-translation. Added rounds remain blank. Captured running plan remains unchanged.
- Numbers: both-mode hours/minutes/seconds, loop wait and count use existing limits. Discrete wheel adjusts one; precise trackpad deltas accumulate; momentum ignored; only enabled visible hovered fields in the active app window consume events. Active typed text must win over stale field value; invalid draft remains for normal validation. Date pickers retain native segments/stepper.
- Acceptance: build/tests plus independent source review establish implementation; owner repeats Safari trial, sibling-window/sheet refusal and physical wheel tests before native acceptance or formal release.
- Delivery: preview series 1.2.0-preview.2, updated Mac bundle 1.2.0/build 12004; Windows candidate metadata remains preview.2. Mac title exposes the build.

- Repeated-failure correction: AXFocusedApplication identifies the live keyboard owner; NSWorkspace PID is diagnostic comparison only. A separate activation request stage waits one configured step delay before revalidating and clicking. Cancellation/deadline/late checks apply to this stage. No queued paste or retries. Capture supports regular app windows only, refusing inaccessible/system/accessory targets without searching under them. AX permission is requested before capture countdown.
- Diagnostics: user-triggered clipboard copy only while idle; bounded in-memory trace includes build/OS, app/PID/AX-window token and stage/error, never prompt/clipboard contents or window title. No file/network persistence.
