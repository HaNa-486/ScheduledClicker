Geplante Klicks und Prompt-Schleifen für Windows

Die portable EXE für Windows 11 benötigt keine Installation. Nutzen Sie feste Uhrzeiten, verzögerte Klicks und begrenzte Prompt-Schleifen in einem Fenster mit fünf Sprachen und umschaltbarer Darstellung.

Zwei Modi in einem Fenster

Der einfache Modus führt einen Einzel- oder Doppelklick zu einer zukünftigen lokalen Uhrzeit oder nach einer Wartezeit aus. Der Schleifenmodus fügt denselben Prompt oder eine Folge ein, klickt auf Senden und wiederholt dies innerhalb der festgelegten Grenzen. Beide Modi teilen Uhr, Sprachauswahl und Darstellungsschalter.

Windows-Kompatibilität

Der einfache Modus unterstützt zukünftige Uhrzeiten oder Verzögerungen von einer Sekunde bis 168 Stunden. Die Positionserfassung erfolgt nach drei Sekunden. Monitorabhängige DPI-Werte und negative Koordinaten werden unterstützt. Die Eingabe läuft mit normalen Benutzerrechten; als Administrator gestartete Zielprogramme können sie ablehnen. Dokumentierte Zielplattform ist Windows 11.

Fünf Sprachen, manuell umschaltbar

Bei chinesischer Systemsprache – einschließlich vereinfachtem Chinesisch – startet die App auf traditionellem Chinesisch. Japanisch, Koreanisch und Deutsch wählen die jeweilige Sprache; sonst wird Englisch verwendet. Beide Modi erlauben einen Wechsel. Auch diese Website bietet oben dieselben fünf Sprachen mit eigenen, teilbaren Seitenadressen an.

Helle und dunkle Darstellung

Die App liest beim Start die Systemdarstellung. Die Sonne/Mond-Schaltfläche schaltet beide Modi für die laufende Sitzung um. Beim nächsten Start wird die Systemeinstellung erneut gelesen.

Häufige Fragen

Verändert ein Sprachwechsel meinen Prompt?

Nur der unveränderte Anfangs-Prompt folgt der Sprache: 繼續, Continue, 続けて, 계속 oder Weiter. Nach einer Bearbeitung oder Löschung bleibt Ihr Inhalt erhalten. Ein laufender Zeitplan verwendet den beim Start festgelegten Prompt.

Warum zeigt mein System eine Warnung?

Die Windows-EXE ist nicht signiert. Die Mac-App ist ad-hoc signiert, ohne Developer-ID-Signatur oder Apple-Notarisierung. Eine Warnung vor einem unbekannten Herausgeber ist etwas anderes als Schadsoftware, eine beschädigte Datei oder eine Organisationssperre. Folgen Sie dem passenden Abschnitt; deaktivieren Sie keine Schutzfunktionen, um die App auszuführen.

Probleme beim Start oder bei der Bedienung?

Melden Sie ein Problem über GitHub Issues; zum Schreiben ist ein GitHub-Konto erforderlich. Geben Sie Betriebssystem, App-Version/Build, Ziel-App, Schritte zur Reproduktion und vollständige Fehlermeldung an. Die Mac-Diagnosekopie liefert Build und Ausführungsphase. Prüfen Sie sie vor dem Veröffentlichen. Keine Prompts, privaten Gespräche oder persönlichen Dateipfade in öffentliche Berichte aufnehmen. Ohne Konto können Sie FAQ und vorhandene Issues lesen.
