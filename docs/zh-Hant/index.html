免費開源 · Windows 與 macOS

定時點擊，循環輸入提示詞。

ScheduledClicker v1.2.0 是免費的本機桌面工具，支援 Windows 11 與 macOS 13 以上。可排程滑鼠點擊，或重複輸入提示詞並點擊送出，提供五語系及深淺色介面。

同一視窗，兩種模式

簡單模式可在指定的未來本機時間，或倒數後執行一次單擊或雙擊。循環模式會貼上相同提示詞或依序輸入內容、點擊送出，並在設定限制內重複。兩種模式共用即時時鐘、語言選單與外觀按鈕。

五語系，可自行切換

程式啟動時，任何中文系統語系（含簡體中文）會顯示繁體中文；日文、韓文與德文系統顯示對應語言，其餘顯示英文。兩種模式都可切換語言。官網也提供這五種語言，可用頂端連結切換，每種語言都有可分享的獨立頁面。

深色與淺色外觀

程式開啟時讀取系統外觀。日／月圖示可切換本次使用期間兩種模式的外觀；重新開啟時會再次讀取系統設定。

本機運作與剪貼簿

程式沒有網路存取、帳號、廣告或遙測。循環模式會覆寫系統剪貼簿，不會還原原本內容；文字可能留在剪貼簿歷程或目標草稿。簡單模式不使用剪貼簿。Mac 的「複製診斷」也會在按下時覆寫剪貼簿。排程與擷取位置不會跨重啟保存。

常見問題

應該下載哪個檔案？

Windows 請選 ScheduledClicker.exe；Mac 請選 ScheduledClicker-macOS-universal.zip，Apple silicon 與 Intel 共用同一檔案。.sha256 是校驗文字檔，不是程式。GitHub 的 Source code ZIP／TAR 是原始碼，不是可直接執行的 App。正式版下載不需要登入。

兩種模式各能做什麼？

簡單模式可在指定的未來本機時間，或倒數後執行一次單擊或雙擊。循環模式會貼上相同提示詞或依序輸入內容、點擊送出，並在設定限制內重複。兩種模式共用即時時鐘、語言選單與外觀按鈕。

會判斷 AI 完成或重設用量限制嗎？

請讓電腦保持喚醒、不鎖屏，目標視窗、輸入框與對話保持不變。固定座標無法辨識切換過的對話或移動過的欄位，送出點擊也不代表訊息已送達。工具不讀取 AI 回覆、不繞過用量限制，也不偵測重設時間。

開啟或使用時遇到問題？

請到 GitHub Issues 回報（發文需要 GitHub 帳號）。提供 Windows／macOS 版本、程式版本／build、目標 App、重現步驟與完整錯誤。Mac 可用「複製診斷」取得建置及執行階段資訊，貼出前請先檢查。公開回報不要包含提示詞、私人對話或個人檔案路徑。沒有帳號時，可先查閱常見問題及既有 Issues。
