Windows：インストール不要のアプリを開く

  1. Windows ボタンから ScheduledClicker.exe をダウンロードし、実行したいローカルフォルダーに置きます。インストールウィザードはありません。
  2. 下記の Windows 検証手順でファイルを確認し、EXE をダブルクリックします。
  3. 開いたらシンプルモードで無害なクリックを 1 回試してください。ループは使い捨ての文字で確認してから実際の会話で使います。

OS の警告が表示されるのはなぜ？

未認識のアプリとして SmartScreen に「Windows によって PC が保護されました」と表示された場合は、公式の入手先とチェックサムを確認します。続行を選ぶ場合、Windows に選択肢があれば「詳細情報」→「実行」を選べます。未署名のため発行元が不明と表示される場合があります。マルウェア、防ウイルス検出、管理対象端末の制限の場合は停止し、問題を報告するか管理者に確認してください。SmartScreen や防ウイルスを無効にしないでください。ハッシュの一致だけで安全性は保証されません。

macOS：インストールと権限設定

  1. Mac ボタンから ScheduledClicker-macOS-universal.zip をダウンロードし、展開前に ZIP を検証します。Safari が自動展開した場合は ScheduledClicker.app が既にあることがあります。検証するには元の ZIP を保存するか再取得してください。
  2. 必要なら ZIP をダブルクリックして展開し、Finder で ScheduledClicker.app を「アプリケーション」にドラッグします。PKG や Apple silicon 専用の別ファイルはありません。
  3. 「アプリケーション」から起動します。開発元や公証を確認できない場合は、下の起動手順を確認してください。
  4. 「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」で ScheduledClicker を有効にします。一覧になければ + から「アプリケーション」内のアプリを追加します。必要なら Mac の認証を行い、権限が反映されなければ終了して開き直します。
  5. シンプルモードで無害なクリックを試します。ループは同じ表示中の対象ウィンドウで入力欄と送信ボタンを取得し、使い捨ての文字で 1 回試してください。この権限は他のアプリの操作を許可するため、信頼するアプリにのみ与えてください。

OS の警告が表示されるのはなぜ？

開発元不明・未公証の警告では、まず一度アプリを開こうとします。公式ダウンロードを信頼する場合は「システム設定」→「プライバシーとセキュリティ」の ScheduledClicker に関する表示で「このまま開く」を選び、表示された確認で「開く」を選択します。マルウェアや破損の警告にはこの対処を使わず、停止して正確な文面を報告してください。Gatekeeper を無効にしたり、ターミナルで隔離属性を削除したりしないでください。

OS の公式ガイド

旧版やプレビュー版を置き換える前にアプリを終了してください。新しいアプリを「アプリケーション」に移し、アクセシビリティ権限を再確認します。許可済み項目が旧ファイルを指して権限が機能しない場合は、旧項目を削除して現在のアプリを追加し、開き直します。座標は再取得してください。v1.2.0 と build12004 はリリース版と内部ビルド番号で、別々のダウンロードではありません。

ダウンロードファイルの検証方法

チェックサムは公開ファイルとの一致を確認するもので、作成者の信頼性を独立に証明するものではありません。対応する .sha256 をテキストとして開き、64 文字のハッシュとコマンド結果を比較します。大文字・小文字は区別しません。不一致なら起動せず公式リンクから再取得し、繰り返す場合は報告してください。

Windows · PowerShell

Windows：PowerShell を開き、例のパスを実際の EXE の場所に置き換えます（エクスプローラーでファイルを右クリック→パスのコピー）。下記を実行し、Hash 欄と ScheduledClicker-Windows.sha256 を比較します。フルパスを使うので現在のフォルダーは問いません。

例：ダウンロードしたファイルの実際のパスに置き換えてください。

Get-FileHash -LiteralPath "C:\Users\YOUR_NAME\Downloads\ScheduledClicker.exe" -Algorithm SHA256

SHA-256 チェックサム（テキスト）

macOS · Terminal

Mac：「ターミナル」に shasum -a 256 と空白を入力し、Finder から元の ZIP をドラッグしてフルパスを挿入し、Return を押します。先頭 64 文字と ScheduledClicker-macOS-universal.sha256 を比較します。パスを手入力する場合、空白を含むパスは引用符で囲みます。

例：ダウンロードしたファイルの実際のパスに置き換えてください。

shasum -a 256 "/Users/YOUR_NAME/Downloads/ScheduledClicker-macOS-universal.zip"

旧版からの更新

旧アプリを終了し、公式 v1.2.0 ファイルに置き換えます。Actions の成果物や GitHub ログインは不要です。スケジュールと取得位置は保存されないので再設定します。戻す必要がある場合だけ旧ファイルを別に保存してください。過去の版には現在のループ機能の一部がありません。

よくある質問

どのファイルをダウンロードすればよいですか？

Windows は ScheduledClicker.exe、Mac は ScheduledClicker-macOS-universal.zip です。Apple silicon と Intel は同じ ZIP を使います。.sha256 は検証用テキストで、アプリではありません。GitHub の Source code ZIP／TAR はソースコードで、そのまま使えるアプリではありません。正式版のダウンロードにログインは不要です。

システムの警告が出るのはなぜですか？

Windows EXE は未署名です。Mac は ad-hoc 署名で、Developer ID 署名・Apple 公証はありません。発行元不明の警告は、マルウェア、破損、組織ポリシーによるブロックとは異なります。下記の該当する手順に従い、保護機能を無効にしないでください。

起動や操作で困ったら

GitHub Issues から報告できます（投稿には GitHub アカウントが必要）。OS とアプリのバージョン／ビルド、対象アプリ、再現手順、エラー全文を記載してください。Mac の診断コピーでビルドや実行段階を確認できます。公開前に内容を確認し、プロンプト、私的な会話、個人のファイルパスを含めないでください。アカウントがない場合は FAQ や既存の Issues を参照できます。
