Windows: portable Anwendung öffnen

  1. Laden Sie ScheduledClicker.exe über die Windows-Schaltfläche herunter und legen Sie sie in einem lokalen Ordner ab. Es gibt keinen Installationsassistenten.
  2. Prüfen Sie die Datei mit der Windows-Anleitung unten und öffnen Sie die EXE per Doppelklick.
  3. Testen Sie nach dem Start zunächst einen harmlosen Klick im einfachen Modus. Prüfen Sie eine Schleife mit entbehrlichem Text, bevor Sie einen echten Chat verwenden.

Warum erscheint eine Systemwarnung?

Meldet SmartScreen wegen einer unbekannten App, dass der Computer geschützt wurde, prüfen Sie zunächst Downloadquelle und Prüfsumme. Wenn Sie fortfahren möchten und Windows die Option anbietet, wählen Sie Weitere Informationen → Trotzdem ausführen. Bei dieser nicht signierten Version kann der Herausgeber als unbekannt erscheinen. Bei Schadsoftwaremeldungen, Virenscannerfunden oder Einschränkungen verwalteter Geräte halten Sie an und melden das Problem oder fragen Ihre Administration. Deaktivieren Sie weder SmartScreen noch Virenschutz. Eine passende Prüfsumme allein garantiert keine Sicherheit.

macOS: installieren und Zugriff erlauben

  1. Laden Sie ScheduledClicker-macOS-universal.zip über die Mac-Schaltfläche herunter und prüfen Sie die ZIP vor dem Entpacken. Falls Safari sie bereits entpackt hat, kann ScheduledClicker.app schon vorliegen. Bewahren Sie die ursprüngliche ZIP auf oder laden Sie sie für die Prüfsumme erneut herunter.
  2. Entpacken Sie die ZIP bei Bedarf per Doppelklick. Ziehen Sie ScheduledClicker.app im Finder nach Programme. Es gibt keinen PKG-Installer und keinen separaten Apple-silicon-Download.
  3. Öffnen Sie die App aus Programme. Falls macOS Entwickler oder Notarisierung nicht überprüfen kann, lesen Sie den passenden Abschnitt unten.
  4. Aktivieren Sie ScheduledClicker unter Systemeinstellungen → Datenschutz & Sicherheit → Bedienungshilfen. Fehlt der Eintrag, fügen Sie die App aus Programme mit + hinzu. Bestätigen Sie bei Bedarf mit Ihren Mac-Anmeldedaten. Wird die Erlaubnis nicht erkannt, beenden und öffnen Sie ScheduledClicker erneut.
  5. Testen Sie einen harmlosen Klick im einfachen Modus. Für eine Schleife erfassen Sie Eingabe und Senden im selben sichtbaren Zielfenster und testen eine Runde mit entbehrlichem Text. Die Berechtigung erlaubt die Steuerung anderer Apps; erteilen Sie sie nur einer vertrauenswürdigen Anwendung.

Warum erscheint eine Systemwarnung?

Bei einer Warnung vor unbekanntem Entwickler oder fehlender Notarisierung versuchen Sie zunächst einmal, die App zu öffnen. Wenn Sie diesem offiziellen Download vertrauen, suchen Sie unter Systemeinstellungen → Datenschutz & Sicherheit den Hinweis zu ScheduledClicker und wählen Dennoch öffnen. Bestätigen Sie Öffnen, falls angeboten. Verwenden Sie diesen Weg nicht bei einer Schadsoftware- oder Beschädigungswarnung: stoppen Sie und melden Sie den genauen Wortlaut. Deaktivieren Sie Gatekeeper nicht und entfernen Sie keine Quarantänemarkierung per Terminal.

Offizielle Hilfe zum Betriebssystem

Verweist der erlaubte Eintrag auf die alte Kopie und funktioniert der Zugriff weiterhin nicht, entfernen Sie diesen Eintrag und fügen die aktuelle App aus Programme hinzu. Download überprüfen · Problem melden

Download überprüfen

Eine Prüfsumme bestätigt die Übereinstimmung mit der veröffentlichten Datei, nicht unabhängig die Vertrauenswürdigkeit des Urhebers. Öffnen Sie die passende .sha256-Datei als Text und vergleichen Sie ihren 64-stelligen Hash mit der Befehlsausgabe. Groß-/Kleinschreibung spielt keine Rolle. Bei Abweichung nicht starten: erneut offiziell herunterladen und einen wiederholten Unterschied melden.

Windows · PowerShell

Windows: Öffnen Sie PowerShell. Ersetzen Sie den Beispielpfad durch den tatsächlichen Pfad zur EXE (Explorer → Rechtsklick auf die Datei → Als Pfad kopieren). Vergleichen Sie das Feld Hash der folgenden Ausgabe mit ScheduledClicker-Windows.sha256. Der vollständige Pfad funktioniert unabhängig vom aktuellen PowerShell-Ordner.

Nur ein Beispiel – ersetzen Sie den Pfad durch Ihre heruntergeladene Datei:

Get-FileHash -LiteralPath "C:\Users\YOUR_NAME\Downloads\ScheduledClicker.exe" -Algorithm SHA256

SHA-256-Prüfsumme (Textdatei)

macOS · Terminal

Mac: Öffnen Sie Terminal, geben Sie shasum -a 256 und ein Leerzeichen ein und ziehen Sie die ursprüngliche ZIP aus dem Finder ins Terminal. Dadurch wird der vollständige Pfad eingefügt. Drücken Sie Return und vergleichen Sie die ersten 64 Zeichen mit ScheduledClicker-macOS-universal.sha256. Bei manueller Eingabe müssen Pfade mit Leerzeichen in Anführungszeichen stehen.

Nur ein Beispiel – ersetzen Sie den Pfad durch Ihre heruntergeladene Datei:

shasum -a 256 "/Users/YOUR_NAME/Downloads/ScheduledClicker-macOS-universal.zip"

Häufige Fragen

Welche Datei soll ich herunterladen?

Unter Windows wählen Sie ScheduledClicker.exe, auf dem Mac ScheduledClicker-macOS-universal.zip. Apple silicon und Intel verwenden dieselbe ZIP. .sha256-Dateien sind Prüfsummen als Text, keine Anwendungen. GitHubs Source code ZIP/TAR enthält Quellcode und keine direkt startbare App. Offizielle Downloads benötigen keine Anmeldung.

Warum zeigt mein System eine Warnung?

Die Windows-EXE ist nicht signiert. Die Mac-App ist ad-hoc signiert, ohne Developer-ID-Signatur oder Apple-Notarisierung. Eine Warnung vor einem unbekannten Herausgeber ist etwas anderes als Schadsoftware, eine beschädigte Datei oder eine Organisationssperre. Folgen Sie dem passenden Abschnitt; deaktivieren Sie keine Schutzfunktionen, um die App auszuführen.

Probleme beim Start oder bei der Bedienung?

Melden Sie ein Problem über GitHub Issues; zum Schreiben ist ein GitHub-Konto erforderlich. Geben Sie Betriebssystem, App-Version/Build, Ziel-App, Schritte zur Reproduktion und vollständige Fehlermeldung an. Die Mac-Diagnosekopie liefert Build und Ausführungsphase. Prüfen Sie sie vor dem Veröffentlichen. Keine Prompts, privaten Gespräche oder persönlichen Dateipfade in öffentliche Berichte aufnehmen. Ohne Konto können Sie FAQ und vorhandene Issues lesen.
