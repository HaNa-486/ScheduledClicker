ScheduledClicker 질문과 답변

최신 Windows 및 Mac 파일, 설치 경고, 언어, 화면 모드, 프롬프트 반복과 취소 방법을 확인하세요.

다운로드 및 설치

자주 묻는 질문

어떤 파일을 다운로드해야 하나요?

Windows는 ScheduledClicker.exe, Mac은 ScheduledClicker-macOS-universal.zip을 선택하세요. Apple silicon과 Intel은 같은 ZIP을 사용합니다. .sha256은 검증용 텍스트이지 앱이 아닙니다. GitHub의 Source code ZIP/TAR는 소스 코드이며 바로 실행할 앱이 아닙니다. 공식 릴리스 다운로드에는 로그인이 필요 없습니다.

시스템에서 경고가 뜨는 이유는 무엇인가요?

Windows EXE는 서명되지 않았습니다. Mac 앱은 ad-hoc 서명이며 Developer ID 서명이나 Apple 공증은 없습니다. 알 수 없는 게시자 경고는 악성 코드, 파일 손상, 조직 정책 차단과 다릅니다. 해당 상황의 안내를 따르며 앱을 실행하려고 시스템 보호를 끄지 마세요.

두 모드에서는 무엇을 할 수 있나요?

간단 모드는 미래의 로컬 시각이나 대기 시간을 정해 한 번의 단일 또는 더블 클릭을 실행합니다. 반복 모드는 같은 프롬프트나 순서별 내용을 붙여넣고 전송을 클릭하며 설정한 제한 안에서 반복합니다. 두 모드는 실시간 시계, 언어 선택과 테마 버튼을 공유합니다.

어떤 언어를 지원하나요?

앱 시작 시 중국어 시스템은 간체 설정을 포함해 번체 중국어로, 일본어·한국어·독일어 시스템은 해당 언어로, 나머지는 영어로 표시됩니다. 두 모드에서 언어를 바꿀 수 있습니다. 웹사이트도 위쪽 링크로 같은 5개 언어를 선택하며 언어별 페이지를 따로 공유할 수 있습니다.

라이트/다크 모드는 어떻게 바꾸나요?

앱은 시작할 때 시스템 화면 모드를 확인합니다. 해/달 버튼은 현재 실행 중인 두 모드의 화면을 바꿉니다. 앱을 다시 시작하면 시스템 설정을 다시 읽습니다.

언어를 바꾸면 프롬프트도 바뀌나요?

아직 편집하지 않은 초기 프롬프트만 언어에 맞춰 바뀝니다: 繼續, Continue, 続けて, 계속, Weiter. 편집하거나 지운 뒤에는 사용자 내용을 유지합니다. 실행 중인 예약은 시작할 때 확정한 프롬프트를 사용합니다.

반복 간격은 언제부터 계산하나요?

각 회차의 동작이 끝난 뒤 대기를 시작합니다. 최대 횟수 또는 종료 시각을 적어도 하나 설정해야 하며 둘 다 설정하면 먼저 도달한 조건에서 멈춥니다. 클릭과 붙여넣기 사이의 지연은 회차 사이 대기와 별개입니다. AI 서비스의 사용량 주기와 자동 동기화되지 않습니다.

일시 정지, 취소와 긴급 중지는 어떻게 작동하나요?

회차 사이에 일시 정지하면 재개할 때 남은 대기 시간을 유지하지만 종료 시각은 계속 적용됩니다. 회차 실행 중 일시 정지하면 그 회차를 중단합니다. 취소, F8(일부 Mac 키보드는 Fn+F8) 또는 앱 종료는 이후 동작을 멈추지만 붙여넣은 글이나 완료한 클릭을 취소하지 못합니다. 다시 시작하기 전에 초안을 확인하세요.

클립보드와 데이터는 어떻게 처리하나요?

앱에는 네트워크 접근, 계정, 광고, 원격 측정이 없습니다. 반복 모드는 클립보드를 덮어쓰며 이전 내용을 복원하지 않습니다. 텍스트가 클립보드 기록이나 대상 초안에 남을 수 있습니다. 간단 모드는 클립보드를 사용하지 않습니다. Mac의 진단 복사도 버튼을 누를 때 클립보드를 덮어씁니다. 예약과 위치는 재시작 후 보존되지 않습니다.

AI 완료를 감지하거나 사용량 제한을 초기화하나요?

컴퓨터를 절전 또는 잠금 상태로 두지 말고 대상 창, 입력란과 대화를 그대로 유지하세요. 고정 좌표는 다른 대화나 이동한 입력란을 구별하지 못합니다. 전송 클릭은 전달 완료를 보장하지 않습니다. AI 답변 확인, 사용량 제한 우회, 초기화 시각 감지는 하지 않습니다.

무엇을 검증했나요?

소유자가 Mac build12004 기능과 Windows 초기 프롬프트 언어 전환, 편집한 내용 보존, 반복 시험 실행을 확인했습니다. 두 플랫폼의 자동 빌드, 예약, 번역 및 UI 검사를 통과했습니다. 모든 외부 앱, 화면 구성, 권한 거부 상황 또는 실제 긴급 중지 키 동작을 각각 검증했다는 뜻은 아닙니다.

Mac에서 손쉬운 사용 권한이 왜 필요한가요?

다른 앱을 제어하려면 손쉬운 사용 권한이 필요합니다. 반복 모드는 위치 지정 전, 간단 모드는 입력 예약 전에 권한을 확인합니다. 같은 일반적인 접근 가능한 앱 창에서 두 위치를 지정하세요. Safari 전용이 아닙니다. 시간, 동작 지연과 횟수 필드는 직접 입력, 마우스 휠 및 트랙패드로 조절할 수 있습니다.

실행이나 사용 중 문제가 있나요?

GitHub Issues로 신고하세요(게시하려면 GitHub 계정 필요). OS 및 앱 버전/빌드, 대상 앱, 재현 단계, 전체 오류를 포함하세요. Mac의 진단 복사는 빌드와 실행 단계 정보를 제공합니다. 공개 전에 확인하고 프롬프트, 개인 대화 또는 개인 파일 경로를 포함하지 마세요. 계정이 없어도 FAQ와 기존 Issues는 읽을 수 있습니다.
