What is included?

Simple click scheduling and bounded prompt loops, five languages, system-selected appearance and a manual theme button. Both platforms use the same v1.2.0 feature release; Mac identifies its accepted runtime as build 12004.

Install on Windows

  1. Download the EXE above and compare its checksum.
  2. Run it from a local folder. No installation is required.
  3. Start with a harmless click or one trial loop. Windows may show SmartScreen because the EXE is unsigned.

Install on Mac

  1. Download the ZIP above and compare its checksum.
  2. Extract it once, then move ScheduledClicker.app to Applications.
  3. Open the app. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway for this downloaded app. It is ad-hoc signed and not Apple-notarized.
  4. Allow ScheduledClicker in Privacy & Security → Accessibility before capturing loop positions or scheduling input. After replacing an older copy, check that permission applies to the new app.
  5. Capture both positions again and try one harmless round.

Check the file before opening

The .sha256 files are small text fingerprints, not installers. Compare the output below with the matching checksum file.

Get-FileHash .\ScheduledClicker.exe -Algorithm SHA256
shasum -a 256 ScheduledClicker-macOS-universal.zip

Upgrading from a test build?

v1.2.0 replaces the previous preview downloads. Use the two stable buttons above; you no longer need GitHub Actions artifacts or a GitHub account. Quit the old app before replacing it. Schedules and captured positions are not saved across restarts.

Common questions

Which file should I download?

Windows 11 users need ScheduledClicker.exe. Mac users need ScheduledClicker-macOS-universal.zip, which contains one app for both Apple silicon and Intel. A .sha256 file is a text checksum, not an installer. Official release downloads do not require a GitHub account.

Why might Windows or macOS warn when opening it?

The Windows EXE is unsigned. The Mac app is ad-hoc signed, not Apple Developer ID signed or notarized. Use the official release, verify its SHA-256 and review the platform-specific opening instructions.
