Download & Installation

Häufige Fragen

Welche Datei soll ich herunterladen?

Unter Windows wählen Sie ScheduledClicker.exe, auf dem Mac ScheduledClicker-macOS-universal.zip. Apple silicon und Intel verwenden dieselbe ZIP. .sha256-Dateien sind Prüfsummen als Text, keine Anwendungen. GitHubs Source code ZIP/TAR enthält Quellcode und keine direkt startbare App. Offizielle Downloads benötigen keine Anmeldung.

Warum zeigt mein System eine Warnung?

Die Windows-EXE ist nicht signiert. Die Mac-App ist ad-hoc signiert, ohne Developer-ID-Signatur oder Apple-Notarisierung. Eine Warnung vor einem unbekannten Herausgeber ist etwas anderes als Schadsoftware, eine beschädigte Datei oder eine Organisationssperre. Folgen Sie dem passenden Abschnitt; deaktivieren Sie keine Schutzfunktionen, um die App auszuführen.

Was können die beiden Modi?

Der einfache Modus führt einen Einzel- oder Doppelklick zu einer zukünftigen lokalen Uhrzeit oder nach einer Wartezeit aus. Der Schleifenmodus fügt denselben Prompt oder eine Folge ein, klickt auf Senden und wiederholt dies innerhalb der festgelegten Grenzen. Beide Modi teilen Uhr, Sprachauswahl und Darstellungsschalter.

Welche Sprachen werden unterstützt?

Bei chinesischer Systemsprache – einschließlich vereinfachtem Chinesisch – startet die App auf traditionellem Chinesisch. Japanisch, Koreanisch und Deutsch wählen die jeweilige Sprache; sonst wird Englisch verwendet. Beide Modi erlauben einen Wechsel. Auch diese Website bietet oben dieselben fünf Sprachen mit eigenen, teilbaren Seitenadressen an.

Wie wechsle ich zwischen heller und dunkler Darstellung?

Die App liest beim Start die Systemdarstellung. Die Sonne/Mond-Schaltfläche schaltet beide Modi für die laufende Sitzung um. Beim nächsten Start wird die Systemeinstellung erneut gelesen.

Verändert ein Sprachwechsel meinen Prompt?

Nur der unveränderte Anfangs-Prompt folgt der Sprache: 繼續, Continue, 続けて, 계속 oder Weiter. Nach einer Bearbeitung oder Löschung bleibt Ihr Inhalt erhalten. Ein laufender Zeitplan verwendet den beim Start festgelegten Prompt.

Wann beginnt das Schleifenintervall?

Die Wartezeit beginnt nach Abschluss jeder Runde. Mindestens eine Begrenzung durch Rundenzahl oder Endzeit ist nötig; sind beide aktiv, beendet die zuerst erreichte Bedingung die Schleife. Die Verzögerung zwischen Klicks und Einfügen ist vom Rundenintervall getrennt. Es gibt keine Synchronisierung mit dem Nutzungslimit eines KI-Dienstes.

Wie funktionieren Pause, Abbruch und Notstopp?

Eine Pause zwischen Runden bewahrt die verbleibende Wartezeit für das Fortsetzen; die Endzeit gilt weiter. Eine Pause während einer Runde stoppt diese. Abbruch, F8 (auf manchen Mac-Tastaturen Fn+F8) oder Schließen der App verhindert weitere Schritte, kann aber eingefügten Text oder ausgeführte Klicks nicht zurücknehmen. Prüfen Sie vor einem Neustart den Entwurf auf Duplikate.

Was geschieht mit Zwischenablage und Daten?

Die App verwendet keinen Netzwerkzugriff, kein Konto, keine Werbung und keine Telemetrie. Der Schleifenmodus überschreibt die Zwischenablage, ohne den vorherigen Inhalt wiederherzustellen. Text kann im Verlauf oder im Zielentwurf bleiben. Der einfache Modus verwendet keine Zwischenablage. Auch die Mac-Diagnosekopie überschreibt sie beim Betätigen. Zeitpläne und Positionen werden nicht über einen Neustart gespeichert.

Erkennt die App KI-Abschluss oder setzt sie Nutzungslimits zurück?

Der Computer muss wach und entsperrt bleiben; Zielfenster, Eingabefeld und Gespräch dürfen sich nicht ändern. Feste Koordinaten erkennen weder einen anderen Chat noch ein verschobenes Feld. Ein Sendeklick bestätigt keine Zustellung. Die App liest keine KI-Antworten, umgeht keine Nutzungslimits und erkennt keine Rücksetzzeitpunkte.

Was wurde überprüft?

Der Eigentümer hat die Funktionen von Mac build12004 sowie unter Windows Sprachwechsel des Anfangs-Prompts, Erhalt eigener Texte und einen Schleifentest bestätigt. Automatisierte Builds, Zeitplan-, Sprach- und UI-Prüfungen beider Plattformen waren erfolgreich. Das belegt nicht jede Fremdanwendung, Bildschirmkonfiguration, verweigerte Berechtigung oder Betätigung der physischen Notstopptaste.

Warum benötigt der Mac die Berechtigung Bedienungshilfen?

Die Steuerung anderer Apps benötigt die Berechtigung Bedienungshilfen. Der Schleifenmodus fragt vor der Erfassung danach, der einfache Modus prüft sie vor dem Planen der Eingabe. Erfassen Sie beide Punkte im selben regulären, zugänglichen App-Fenster. Die Unterstützung ist nicht auf Safari beschränkt. Zahlenfelder für Dauer, Aktionsabstand und Rundenzahl lassen sich per Tastatur, Mausrad oder Trackpad ändern.

Probleme beim Start oder bei der Bedienung?

Melden Sie ein Problem über GitHub Issues; zum Schreiben ist ein GitHub-Konto erforderlich. Geben Sie Betriebssystem, App-Version/Build, Ziel-App, Schritte zur Reproduktion und vollständige Fehlermeldung an. Die Mac-Diagnosekopie liefert Build und Ausführungsphase. Prüfen Sie sie vor dem Veröffentlichen. Keine Prompts, privaten Gespräche oder persönlichen Dateipfade in öffentliche Berichte aufnehmen. Ohne Konto können Sie FAQ und vorhandene Issues lesen.
