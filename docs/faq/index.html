Common questions

What is the latest ScheduledClicker version?

The latest stable release is v1.2.0, released on October 15, 2026, for Windows 11 and macOS 13 or later. Download the Windows EXE or the universal macOS ZIP from the official download page.

What is ScheduledClicker?

ScheduledClicker is a free, open-source desktop tool for one scheduled mouse click or bounded recurring prompt input and send clicks. Version 1.2.0 includes simple and loop modes, five interface languages and light/dark switching on Windows and macOS.

Which file should I download?

Windows 11 users need ScheduledClicker.exe. Mac users need ScheduledClicker-macOS-universal.zip, which contains one app for both Apple silicon and Intel. A .sha256 file is a text checksum, not an installer. Official release downloads do not require a GitHub account.

Does ScheduledClicker support repeating prompts?

Yes. Version 1.2.0 includes loop mode: use the same prompt every round or a sequence, capture the input and Send positions, and stop after a maximum round count or deadline. Trial mode performs real input and a send click.

How does the loop interval work?

The interval begins after each round completes. At least one maximum-round or deadline limit is required; when both are enabled, the first reached stops the loop. A fixed interval is not synchronized with an AI service usage reset.

Which interface languages are available?

Traditional Chinese, English, Japanese, Korean and German. Chinese system locales, including Simplified Chinese, select the Traditional Chinese interface; Japanese, Korean and German select their matching language; all others select English. You can switch languages in either mode.

Does the app follow my system appearance?

Yes. Startup follows the system light or dark app appearance. The sun/moon button changes both modes for the current session. Restarting reads the system preference again.

Will language switching change my prompt?

Only the untouched initial continuation prompt follows language changes: 繼續, Continue, 続けて, 계속 or Weiter. Once you edit it, your text is preserved. Prompts already captured by a running schedule stay unchanged.

Does loop mode use the clipboard?

Yes. It overwrites the clipboard to paste prompts and does not restore the previous contents. Text may remain in clipboard history or the target app. Simple mode does not use the clipboard; manually copying Mac diagnostics also replaces it.

What happens when I pause or cancel?

Pause and Resume preserve the remaining wait between rounds; the deadline still applies. Pausing during a round stops it. Cancel, F8 or closing the app stops remaining steps but cannot undo pasted text or completed clicks. Inspect drafts before restarting.

Why does macOS need Accessibility permission?

macOS requires your approval for pointer and keyboard control. Grant ScheduledClicker permission in System Settings → Privacy & Security → Accessibility. Loop mode needs permission before capturing positions and supports regular accessible app windows.

Will it detect AI completion or bypass usage limits?

No. It does not inspect AI responses, detect quota resets, bypass limits or verify delivery. It performs the configured local input and clicks. Keep the computer awake and unlocked, with the target window and chat unchanged.

Why might Windows or macOS warn when opening it?

The Windows EXE is unsigned. The Mac app is ad-hoc signed, not Apple Developer ID signed or notarized. Use the official release, verify its SHA-256 and review the platform-specific opening instructions.

What was tested for v1.2.0?

The owner reported normal Mac functionality and passed the Windows prompt-language and loop tests. CI checks both builds, scheduling, capture/focus policies, localization and layout. These checks do not guarantee compatibility with every app, display setup or failure scenario.

Is it free and local?

Yes. The app is MIT-licensed, with no ads, accounts, telemetry or network access. Schedules and prompts are not saved by ScheduledClicker after exit. Clipboard contents and text left in other apps can remain.
