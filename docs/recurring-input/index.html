Recurring prompt input and send clicks

Loop mode is included in stable v1.2.0 for Windows and macOS. Choose the timing, prompt sequence and stop conditions yourself.

Set up a bounded loop

  1. Keep the computer awake and unlocked. Keep the target app, chat and layout unchanged.
  2. Choose Loop mode, the first execution time, the wait after each round and the delay between actions.
  3. Choose the same prompt each round or a sequence. A sequence can stop at its end or repeat its final prompt.
  4. Enable a maximum round count, a deadline, or both. At least one is required.
  5. Capture input and Send positions in the same window. Choose insert-at-caret or replace-existing-text.
  6. Review the confirmation and try one round on a harmless target. The trial really pastes and clicks Send.

Timing and stopping

Click the input → wait → paste → wait → click Send → wait the configured interval. macOS first requests target activation and waits one configured step delay before validating and clicking. A five-hour interval begins after the round completes; it is not a provider reset timer.

Pause is resumable only between rounds. During a round it stops execution. The deadline applies while paused. Cancel, F8 (Fn+F8 on some Macs) and closing the app stop remaining steps. Completed input cannot be undone; inspect drafts before restarting.

Targets, clipboard and permissions

Loop mode overwrites the clipboard and does not restore it. Mac capture uses Accessibility hit-testing and retains the original window identity; it supports regular accessible app windows. Window checks cannot identify changed chats or confirm message delivery. If a Mac trial fails, Copy diagnostics reports build, OS, app identity and execution stages without prompt text or window titles.

Common questions

Does ScheduledClicker support repeating prompts?

Yes. Version 1.2.0 includes loop mode: use the same prompt every round or a sequence, capture the input and Send positions, and stop after a maximum round count or deadline. Trial mode performs real input and a send click.

How does the loop interval work?

The interval begins after each round completes. At least one maximum-round or deadline limit is required; when both are enabled, the first reached stops the loop. A fixed interval is not synchronized with an AI service usage reset.

What happens when I pause or cancel?

Pause and Resume preserve the remaining wait between rounds; the deadline still applies. Pausing during a round stops it. Cancel, F8 or closing the app stops remaining steps but cannot undo pasted text or completed clicks. Inspect drafts before restarting.

Will it detect AI completion or bypass usage limits?

No. It does not inspect AI responses, detect quota resets, bypass limits or verify delivery. It performs the configured local input and clicks. Keep the computer awake and unlocked, with the target window and chat unchanged.
