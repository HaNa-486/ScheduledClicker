ScheduledClicker v1.2.0 · Free and open source

Scheduled clicks and prompt loops for Mac

One universal app for macOS 13 or later, on Apple silicon and Intel. Simple and loop modes share native controls, five languages and light/dark appearance.

Download macOS v1.2.0Installation and checksums

Two modes in one window

  • Simple: schedule one single or double click at a future local time or after a delay.
  • Loop: paste the same prompt or a sequence, click Send, wait after completion, then repeat within a round limit or deadline.
  • One live clock, language picker, light/dark action and mode switch. Notices stay visible.
  • Five languages selected from the system at startup, with manual switching. Edited prompts are preserved.

Accessibility and target windows

Grant permission in System Settings → Privacy & Security → Accessibility. Loop mode requests it before capture; simple mode checks it before scheduling input. Capture both points in the same regular accessible app window. The app identifies the target through Accessibility hit-testing and checks the original window identity before input. This works across supported apps, without a Safari-only rule.

Mac controls and troubleshooting

Numeric duration, action-delay and round-count fields support typing, mouse wheel and trackpad adjustments. The shared clock keeps three millisecond digits. If a trial stops, Copy diagnostics includes build, OS, target app and stage information without prompt text or window titles; copying it overwrites the clipboard.

Opening the app

Extract the universal ZIP and move the app to Applications. The app is ad-hoc signed, not Apple Developer ID signed or notarized. If blocked, approve this app in Privacy & Security. Check Accessibility permission again when replacing an older build.

Common questions

Why does macOS need Accessibility permission?

macOS requires your approval for pointer and keyboard control. Grant ScheduledClicker permission in System Settings → Privacy & Security → Accessibility. Loop mode needs permission before capturing positions and supports regular accessible app windows.

What was tested for v1.2.0?

The owner reported normal Mac functionality and passed the Windows prompt-language and loop tests. CI checks both builds, scheduling, capture/focus policies, localization and layout. These checks do not guarantee compatibility with every app, display setup or failure scenario.
