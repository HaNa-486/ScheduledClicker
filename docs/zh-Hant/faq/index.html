常見問題

應該下載哪個檔案？

Windows 請選 ScheduledClicker.exe；Mac 請選 ScheduledClicker-macOS-universal.zip，Apple silicon 與 Intel 共用同一檔案。.sha256 是校驗文字檔，不是程式。GitHub 的 Source code ZIP／TAR 是原始碼，不是可直接執行的 App。正式版下載不需要登入。

為什麼系統會跳出警告？

Windows EXE 尚未簽章。Mac App 使用 ad-hoc 簽章，沒有 Developer ID 簽章或 Apple 公證。未知發行者提醒，與惡意程式、檔案損毀或組織政策阻擋不同。請依下方對應情境處理，不要為了執行程式而關閉系統防護。

兩種模式各能做什麼？

簡單模式可在指定的未來本機時間，或倒數後執行一次單擊或雙擊。循環模式會貼上相同提示詞或依序輸入內容、點擊送出，並在設定限制內重複。兩種模式共用即時時鐘、語言選單與外觀按鈕。

支援哪些語言？

程式啟動時，任何中文系統語系（含簡體中文）會顯示繁體中文；日文、韓文與德文系統顯示對應語言，其餘顯示英文。兩種模式都可切換語言。官網也提供這五種語言，可用頂端連結切換，每種語言都有可分享的獨立頁面。

如何切換深色與淺色外觀？

程式開啟時讀取系統外觀。日／月圖示可切換本次使用期間兩種模式的外觀；重新開啟時會再次讀取系統設定。

切換語言會改掉我的提示詞嗎？

只有尚未編輯的初始提示詞會隨語言改變：繼續、Continue、続けて、계속、Weiter。一旦編輯或刪除，程式就保留你的內容。執行中的排程使用啟動時已確定的提示詞。

循環間隔從何時開始算？

每輪操作完成後才開始等待。至少要啟用最多輪數或截止時間之一；兩者都啟用時，先到達者停止循環。點擊與貼上之間的步驟等待，和每輪之間的間隔是不同設定；間隔不會與 AI 服務的用量視窗自動同步。

暫停、取消與緊急停止有什麼差別？

在輪次之間暫停時，繼續可保留剩餘等待時間，但截止時間仍有效。在一輪執行中暫停會停止該輪。取消、F8（部分 Mac 鍵盤需 Fn+F8） 或關閉程式會停止後續步驟，不能撤回已貼上的文字或已發生的點擊。重新啟動前請檢查草稿，避免重複送出。

剪貼簿與資料會如何處理？

程式沒有網路存取、帳號、廣告或遙測。循環模式會覆寫系統剪貼簿，不會還原原本內容；文字可能留在剪貼簿歷程或目標草稿。簡單模式不使用剪貼簿。Mac 的「複製診斷」也會在按下時覆寫剪貼簿。排程與擷取位置不會跨重啟保存。

會判斷 AI 完成或重設用量限制嗎？

請讓電腦保持喚醒、不鎖屏，目標視窗、輸入框與對話保持不變。固定座標無法辨識切換過的對話或移動過的欄位，送出點擊也不代表訊息已送達。工具不讀取 AI 回覆、不繞過用量限制，也不偵測重設時間。

已驗證哪些項目？

使用者已驗收 Mac build12004 功能，並通過 Windows 預設提示詞語系切換、自訂文字保留及循環試跑。兩平台通過自動建置、排程、語系與介面檢查；這不代表所有第三方程式、螢幕配置、拒絕授權情境或實體緊急停止操作都已個別驗證。

為什麼 Mac 需要輔助使用權限？

控制其他程式需要「輔助使用」權限。循環模式在擷取前請求授權，簡單模式在排程輸入前檢查。請在同一個一般且可存取的 App 視窗擷取兩個位置，並非只支援 Safari。時間長度、步驟等待與輪數等數值欄位可打字，也能使用滑鼠滾輪與觸控板調整。

開啟或使用時遇到問題？

請到 GitHub Issues 回報（發文需要 GitHub 帳號）。提供 Windows／macOS 版本、程式版本／build、目標 App、重現步驟與完整錯誤。Mac 可用「複製診斷」取得建置及執行階段資訊，貼出前請先檢查。公開回報不要包含提示詞、私人對話或個人檔案路徑。沒有帳號時，可先查閱常見問題及既有 Issues。
