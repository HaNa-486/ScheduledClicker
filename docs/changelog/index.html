Version history

What changed—and what did not

A concise public history of application behavior, platform additions, interface fixes, and verification changes.

1.2.0-preview.2 — Candidate, not a stable release

  • Bounded input/send loops with one prompt or a sequence, completion-relative intervals, count/deadline limits, trial, pause and stop.
  • One shared simple/loop window with an always-visible clock and notices.
  • Five interface languages with system selection and manual switching.
  • System-selected startup appearance and manual light/dark action; redesigned visual hierarchy.
  • Windows language dropdown fix and themed date validation; Mac universal candidate and expanded appearance/localization checks.

1.1.2 — Clock and discovery maintenance

  • Improves the macOS three-digit millisecond clock from 10 Hz to roughly 30 Hz.
  • Caches date formatters and keeps clock updates active during control interaction.
  • Adds platform-specific website pages, real UI images, FAQ data, and richer software metadata.
  • Corrects GitHub repository metadata and Release-note formatting.
  • Windows scheduling functionality remains unchanged; its version metadata is updated to match the release.

1.1.1 — macOS Dark Mode usability

  • Fixes white-on-white controls in macOS Dark appearance.
  • Reorganizes time, coordinate, click, action, and status controls.
  • Adds Aqua/Dark Aqua UI checks and actual rendered evidence.
  • Windows scheduling functionality remains unchanged.

1.1.0 — Native macOS edition

  • Adds a native AppKit/Quartz macOS 13+ version.
  • Ships one universal application for Apple silicon and Intel.
  • Adds Accessibility permission checks and macOS CI.
  • The Windows source behavior is unchanged from 1.0.0; only its assembly version and rebuilt hash differ.

1.0.0 — Initial Windows release

  • Windows 11 WinForms interface and live clock.
  • Exact future time and monotonic delay modes.
  • Coordinate capture, single/double click, cancel, and F8 emergency stop.
  • DPI, multi-display, overdue, display-change, and off-screen safety checks.

For exact implementation details, see the repository CHANGELOG.md and GitHub Releases.
