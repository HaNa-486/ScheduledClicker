無料・オープンソース · Windows / macOS

プロンプトループを設定する

回数または終了日時を指定して、同じプロンプトや順番に異なる内容を入力します。Windows / Mac の位置取得、実際の試行、待機、一時停止、キャンセルを説明します。

ダウンロード・インストール
  1. ループモードで初回日時、各回の後の待機時間、操作間隔を設定します。
  2. 最大回数、終了日時、または両方を有効にします。初回試行は 1 回にし、使い捨ての文字を使います。
  3. 毎回同じ内容か順番に異なるプロンプトかを選び、終了後に最後の内容を繰り返すか設定します。既存文字の置換は任意で、初期設定はカーソル位置への挿入です。
  4. それぞれ 3 秒のカウントダウン後に入力欄と送信ボタンを取得します。同じ表示中のウィンドウで取得し、その位置を変えないでください。
  5. 1 回試行して確認画面を読みます。実際に文字を貼り付けて送信をクリックします。結果を確認してから予約を開始してください。クリック完了回数は配信確認ではありません。

編集したプロンプトは保持

言語に合わせて変わるのは未編集の初期プロンプトだけです：繼續、Continue、続けて、계속、Weiter。編集や削除をすると、その内容を保持します。実行中のスケジュールは開始時に確定したプロンプトを使います。

ローカル動作とクリップボード

アプリにネットワークアクセス、アカウント、広告、テレメトリはありません。ループはクリップボードを上書きし、以前の内容を復元しません。履歴や下書きに文字が残る場合があります。シンプルモードはクリップボードを使いません。Mac の診断コピーも押したときに上書きします。スケジュールと座標は再起動後に保存されません。

よくある質問

ループの間隔はいつから数えますか？

各回の操作が完了してから待機が始まります。最大回数または終了日時を少なくとも 1 つ指定し、両方あれば先に達した条件で停止します。クリック・貼り付け間の待機は、各回の間隔とは別です。AI サービスの利用枠とは同期しません。

一時停止、キャンセル、緊急停止はどう動作しますか？

各回の間で一時停止すると、再開時に残りの待機時間を引き継ぎます。終了日時は有効なままです。操作途中の一時停止はその回を停止します。キャンセル、F8（一部の Mac キーボードでは Fn+F8）、アプリを閉じる操作は後続処理を止めますが、貼り付け済みの文字やクリックは取り消せません。再実行前に下書きを確認してください。

AI の完了や利用制限のリセットを検出しますか？

PC をスリープ・ロックさせず、対象ウィンドウ、入力欄、会話を変えないでください。固定座標では会話の切り替えや入力欄の移動を識別できません。送信クリックは配信完了を意味しません。AI の応答、利用制限の回避、リセット時刻の検出には対応しません。

起動や操作で困ったら

GitHub Issues から報告できます（投稿には GitHub アカウントが必要）。OS とアプリのバージョン／ビルド、対象アプリ、再現手順、エラー全文を記載してください。Mac の診断コピーでビルドや実行段階を確認できます。公開前に内容を確認し、プロンプト、私的な会話、個人のファイルパスを含めないでください。アカウントがない場合は FAQ や既存の Issues を参照できます。
