Built from a real workflow

Continue a prepared Codex session after usage resets

When Codex shows that a usage window is exhausted and displays a future reset time, you can prepare the next message in the same session and schedule ScheduledClicker to press Send shortly after access returns—even while you sleep.

Important: ScheduledClicker does not bypass, reset, or increase any ChatGPT or Codex limit. It performs an ordinary local mouse click at the time you choose. Always follow the service terms and the reset time shown in your account.

What it does not do

  • No internet connections
  • No telemetry or analytics
  • No accounts or sign-in
  • No registry or startup entry
  • No personal-file access

What you should know

  • Fixed coordinates can become stale if a window moves
  • Elevated windows may reject standard user input
  • The included EXE is not code-signed
  • Test on a harmless target before unattended use
  • Avoid payments, deletion, publishing, or irreversible actions

Frequently asked questions

What is ScheduledClicker?

A free, open-source Windows 11 desktop utility for scheduling one single or double mouse click at a fixed screen position.

Can it continue a Codex session after the usage window resets?

Yes, if you prepare the message and keep the Codex window open at the same position. Schedule the click shortly after the reset time displayed by Codex. It does not detect or bypass limits.

Is ScheduledClicker safe?

It has no network, telemetry, account, or persistence features and uses no third-party packages. Fixed-coordinate automation still carries misclick risk, so test a harmless target first and review the published source and verification report.

Why can Windows SmartScreen show a warning?

The free executable is not signed with a commercial code-signing certificate. You can compare its SHA-256 hash with the verification report or build it from source using the Windows .NET Framework compiler.

Is it really free?

Yes. ScheduledClicker is available under the permissive MIT License. You may use, copy, modify, and distribute it under the license terms.
