設定提示詞循環

以輪數或截止時間限制，重複同一提示詞或依序輸入不同內容。本指南說明 Windows 與 Mac 的位置擷取、實際試跑、等待、暫停與取消。

下載與安裝
  1. 開啟循環模式，設定首次執行、每輪完成後等待，以及步驟之間的延遲。
  2. 啟用最多輪數、截止時間或兩者。第一次試跑建議只設定一輪，使用可丟棄文字。
  3. 選擇每輪相同提示詞或編輯提示詞序列，設定序列結束後是否重複最後一筆。取代原有輸入為選用，預設在游標處插入。
  4. 分別等待 3 秒後擷取輸入框與送出按鈕，兩點應在同一個可見視窗內，且保持該視窗位置不變。
  5. 點選試跑一輪並確認內容。這會真的貼上文字並點擊送出；先檢查目標結果再啟動排程，完成點擊的輪數不代表送達回執。

保留你編輯過的提示詞

只有尚未編輯的初始提示詞會隨語言改變：繼續、Continue、続けて、계속、Weiter。一旦編輯或刪除，程式就保留你的內容。執行中的排程使用啟動時已確定的提示詞。

本機運作與剪貼簿

程式沒有網路存取、帳號、廣告或遙測。循環模式會覆寫系統剪貼簿，不會還原原本內容；文字可能留在剪貼簿歷程或目標草稿。簡單模式不使用剪貼簿。Mac 的「複製診斷」也會在按下時覆寫剪貼簿。排程與擷取位置不會跨重啟保存。

常見問題

循環間隔從何時開始算？

每輪操作完成後才開始等待。至少要啟用最多輪數或截止時間之一；兩者都啟用時，先到達者停止循環。點擊與貼上之間的步驟等待，和每輪之間的間隔是不同設定；間隔不會與 AI 服務的用量視窗自動同步。

暫停、取消與緊急停止有什麼差別？

在輪次之間暫停時，繼續可保留剩餘等待時間，但截止時間仍有效。在一輪執行中暫停會停止該輪。取消、F8（部分 Mac 鍵盤需 Fn+F8） 或關閉程式會停止後續步驟，不能撤回已貼上的文字或已發生的點擊。重新啟動前請檢查草稿，避免重複送出。

會判斷 AI 完成或重設用量限制嗎？

請讓電腦保持喚醒、不鎖屏，目標視窗、輸入框與對話保持不變。固定座標無法辨識切換過的對話或移動過的欄位，送出點擊也不代表訊息已送達。工具不讀取 AI 回覆、不繞過用量限制，也不偵測重設時間。

開啟或使用時遇到問題？

請到 GitHub Issues 回報（發文需要 GitHub 帳號）。提供 Windows／macOS 版本、程式版本／build、目標 App、重現步驟與完整錯誤。Mac 可用「複製診斷」取得建置及執行階段資訊，貼出前請先檢查。公開回報不要包含提示詞、私人對話或個人檔案路徑。沒有帳號時，可先查閱常見問題及既有 Issues。
