ScheduledClicker v1.2.0 · Free and open source

Scheduled clicks and prompt loops for Windows

A portable Windows 11 EXE with simple and loop modes, five interface languages, a live clock and light/dark switching.

Download Windows v1.2.0Installation and checksums

Two modes in one window

  • Simple: schedule one single or double click at a future local time or after a delay.
  • Loop: paste the same prompt or a sequence, click Send, wait after completion, then repeat within a round limit or deadline.
  • One live clock, language picker, light/dark action and mode switch. Notices stay visible.
  • Five languages selected from the system at startup, with manual switching. Edited prompts are preserved.

Scheduling and compatibility

Simple mode supports an exact future time or a monotonic delay from one second to 168 hours, single/double click and three-second position capture. The app is Per-Monitor V2 DPI-aware and supports negative monitor coordinates. Input runs at normal user privilege; elevated administrator windows may reject it.

Prompt handling

Loop mode clicks the captured input, validates the target, writes the prompt to the clipboard and pastes it, then clicks the captured Send position. The interval begins after the round completes. User-edited prompts stay unchanged when switching languages.

Common questions

Will language switching change my prompt?

Only the untouched initial continuation prompt follows language changes: 繼續, Continue, 続けて, 계속 or Weiter. Once you edit it, your text is preserved. Prompts already captured by a running schedule stay unchanged.

Why might Windows or macOS warn when opening it?

The Windows EXE is unsigned. The Mac app is ad-hoc signed, not Apple Developer ID signed or notarized. Use the official release, verify its SHA-256 and review the platform-specific opening instructions.
