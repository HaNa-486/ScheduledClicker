ScheduledClicker version history

The latest stable version is v1.2.0 for Windows and macOS. Earlier releases remain available for reference.

v1.2.0 · October 15, 2026

  • Bounded prompt input/send loops, same or per-round prompts, completion-relative intervals, count/deadline limits, trial, pause and stop.
  • One shared simple/loop window with an always-visible clock and notices.
  • Traditional Chinese, English, Japanese, Korean and German; untouched starter prompts follow the selected language.
  • System-selected light/dark startup appearance and a shared manual theme action.
  • Windows language-picker and date-input fixes; user-edited prompts preserved.
  • Mac numeric wheel controls, AX hit-window capture to correct Dock misidentification, and copyable diagnostics.
  • Owner functional acceptance on both platforms; automated builds, policy tests and UI checks.

v1.2.0 release notes · Download both platforms

v1.1.2 · August 28, 2026

v1.1.1

v1.0.0
